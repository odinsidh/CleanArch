Задание: Пользователь
Контекст:
Мы пишем ядро системы, где есть пользователи. Без паролей, без ролей, просто база. Потом на этом фундаменте будем строить другие фичи.

Где будем применять:
Пользователь будет участвовать во всех следующих проектах — заказывать товары, открывать счета, бронировать переговорки.

Требования к домену:

У пользователя есть:

Уникальный ID

Email (уникальный в системе)

Имя

Статус (активен / деактивирован)

Дата регистрации

Бизнес-правила:

Нельзя создать двух пользователей с одинаковым email

Пользователя нельзя удалить физически, только деактивировать

При создании пользователь всегда активен

Email и имя не могут быть пустыми

Нужно реализовать юзкейсы:

RegisterUser — создать пользователя (проверив уникальность email)

GetUser — получить информацию о пользователе по ID

DeactivateUser — деактивировать пользователя (не удалить!)
