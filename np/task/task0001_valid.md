Требуемая сущность: User
Поля: Username, Email, Status, Age, Name, Created

Бизнес правила: 

 Один email = один пользователь
> Если пользователь деактивирован, деактивировать уже не нужно (выдать ошибку)
> Пускать только пользователей старше 18 лет
> Имя не может быть пустым
> Дата регистрации

Реализовать:
> Register
> Get
> Deactivate

> GetExistedUserById (input id) готовый.юзер
