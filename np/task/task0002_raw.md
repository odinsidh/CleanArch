ТЗ №2: "Статьи и Черновики" (Новостной Портал)
От кого: Главный редактор
Тема: Система публикации контента

«Слушай, ну юзеры у нас теперь есть, пора им дать возможность что-то писать. Нужна сущность "Статья".

Тут всё просто: у статьи должен быть заголовок, какой-то текст и, конечно, автор. Только смотри, автором может быть только тот юзер, который у нас в системе помечен как "Активен". Если он деактивирован — никакой писанины, рубай на корню.

По статусам: когда статью только создают, она должна быть "Черновиком" (Draft). Текст в черновике может быть любым, хоть пустым. Но! Когда автор захочет её "Опубликовать", проверь: заголовок не должен быть короче 5 символов, а текст — минимум 100 знаков. Иначе это не новость, а ерунда какая-то.

Да, и еще момент: дату публикации проставляй только тогда, когда статус меняется на Published. В черновике она нам не нужна. И дай возможность редактору находить статьи по ID. По БД и API сам решишь потом, мне сейчас главное, чтобы логика публикации не лажала».

Что тут нужно будет сделать (после Юзера):
Сущность Article (Domain):

Поля: ID, AuthorID, Title, Content, Status, PublishedAt.

Методы перехода между состояниями (например, Publish() error).

Use Cases:

CreateDraft (создание заготовки).

PublishArticle (проверка правил и перевод в статус Published).

GetArticle (получение статьи).

Repository Interface:

Сохранение, поиск.
